# MetroBike TLV

A local React, Vite, and TypeScript starter for discovering continuous bike
routes across Tel Aviv, Ramat Gan, and Givatayim.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Create the project from scratch

```bash
npm create vite@latest . -- --template react-ts
npm install
npm install tailwindcss @tailwindcss/vite lucide-react
```

## Run locally

```bash
npm run dev
```

## Validate a change

```bash
npm run build
npm run lint
```

Route distances, continuity scores, and descriptions are illustrative mock data.
They are not official navigation guidance.
